Find the [github repository here](https://github.com/kassandraoftroy/kohaku-cli)

## What is kohaku-cli?

**kohaku-cli** is a bare bones Command Line Interface that can be used as a minimal Ethereum Wallet.

It exposes the main features of [kohaku](https://github.com/ethereum/kohaku) an SDK built by the Ethereum Foundation, containing tools for improving wallet privacy.

The goal of the CLI is to make it more practical and convenient for people to get strong privacy for their financial activity on Ethereum. This guide walks you through using the CLI to actually achieve that end.
